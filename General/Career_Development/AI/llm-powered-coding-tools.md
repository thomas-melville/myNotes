# LLM powered coding tools

3 categories

1. Stand-alone chat
2. IDE-integrated
3. Agentic

1 -> 3 manual to automated

## Stand-alone chat

Runs entirely outside the IDE
only know info you share directly
you decide the response, and making updates

Clarity, it only knows what you've told it.
Full control of your codebase

Manual work on your part to provide info and copy out answers

## IDE integrated

Inside the IDE
can get context from the files open / work space
Tool can make changes for you
tool is gathering context underneath

Reduce manual work, has codebase and can auto make changes

Loss of Clarity and Control
May guess as it doesn't have access to everything
risk of assuming LLM has all the context

## Agentic

LLM directly integrated with codebase.
autonomously interacts with codebase
Suggesting improvements
Single prompt can trigger many models calls
Can be on the terminal or in the IDE
like pair programming where you're watching the other developer code
highest level of automation and freedom to the LLM

highly automated
has multi-file access
workflows

might make assumptions on a higher level
bigger edits may turn into a mess
end up with large amounts of coe you don't understand
